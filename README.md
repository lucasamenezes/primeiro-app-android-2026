Meu Primeiro App Android

Aplicação Android desenvolvida em Kotlin com layouts XML como atividade prática de evolução do projeto de sala de aula.

Funcionalidades

- Entrada de endereço de e-mail (`inputType="textEmailAddress"`).
- Entrada de senha oculta (`inputType="textPassword"`).
- Exibição dos dados informados (e-mail e senha) em uma notificação rápida (`Toast`) ao clicar no botão **Entrar**.

Tecnologias Utilizadas

- Linguagem: Kotlin
- Interface: XML (`ConstraintLayout` e `ViewBinding`)
- IDE recomendada: Android Studio
